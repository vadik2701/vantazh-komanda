# Вантаж Команда

Мобільний і настільний вебдодаток для планування загальних робіт по фірмі.

## Можливості

- окремий захищений вхід для керівника та бригади;
- швидке створення завдання: текст, дата та пріоритет;
- позначки «Обов'язково сьогодні» і «Можна завтра»;
- запуск і завершення роботи з автоматичним підрахунком часу;
- перенесення роботи з обов'язковою причиною та новою датою;
- помітне виділення перенесених і прострочених завдань;
- історія виконаних робіт;
- збереження даних у Cloudflare D1;
- адаптивний інтерфейс для телефона, планшета й ноутбука.

## Доступ

PIN-коди та ключ підпису сесії не зберігаються в GitHub. У середовищі розгортання потрібно налаштувати такі секрети:

| Змінна | Призначення |
| --- | --- |
| `MANAGER_PIN` | PIN-код керівника |
| `CREW_PIN` | PIN-код бригади |
| `SESSION_SECRET` | випадковий секрет для підпису сесій |

Сесія входу зберігається в захищеному HttpOnly cookie протягом 12 годин.

## Локальний запуск

Потрібні Node.js `>=22.13.0` і pnpm `11.25.0`.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Збірка для перевірки:

```bash
pnpm build
```

Для повної локальної роботи з базою даних застосуйте міграції з каталогу `drizzle/` до локальної D1-бази та задайте секрети у локальному середовищі. Файли `.env*` і `.dev.vars*` навмисно виключені з Git.

## Основні каталоги

- `app/` — сторінка програми та серверні API;
- `db/` — схема бази даних;
- `drizzle/` — SQL-міграції;
- `lib/role-auth.ts` — серверна авторизація за ролями;
- `public/` — логотип та інші публічні файли;
- `.openai/hosting.json` — конфігурація Sites і D1.

## Розгортання

Робоча версія розгортається через OpenAI Sites. Публікація виконується із зафіксованого Git-коміту, а секрети задаються окремо в налаштуваннях середовища. Не додавайте справжні PIN-коди або `SESSION_SECRET` у код, GitHub Actions чи файли репозиторію.
